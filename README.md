# matanmill304.github.io

Personal site, served by GitHub Pages from `main`. A single static `index.html` — no build step, no
Jekyll, no dependencies. Edit the file, push, and it is live within a minute or two.

Fonts come from Google Fonts (Newsreader for display, IBM Plex Sans for text, IBM Plex Mono for
labels and figures). The waveform under the header is drawn on a `<canvas>` from a deterministic
speech-like envelope — no image asset, and no randomness, so the page renders identically every
time. Light and dark are both designed; the theme follows the visitor's system setting.
